# IBM SkillsBuild Credentials

This folder contains digital credentials (badges and certificates) earned through IBM SkillsBuild.  
All IBM SkillsBuild credentials are stored here in one place so they are easy to find, verify, and maintain.

Last updated: 2025-12-14  
Owner: AAdrian5122007

---

## Purpose
- Centralize all IBM SkillsBuild credentials in a single, consistent location.  
- Store both human-readable files (badge image, PDF) and machine-readable proofs.
- Make verification, indexing, and lightweight automation straightforward.
